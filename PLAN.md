# SpriteForge — Implementation Plan

## Goal
Single-page browser app to create/edit/preview/export small pixel-art animations (32×32,
up to 64 frames, ≥4 layers). Vanilla TypeScript + Vite. Pure model logic unit-tested;
UI glue exempt but typechecked and reachable from `main.ts`.

## Constraints
- Scripts must exist: `npm run typecheck`, `npm test`, `npm run build`.
- `npm install && npm run build` yields a working app. Node ≥ 18.
- No console errors in normal use (missing navicon 404 tolerated).
- Usable at 1280×800 with no layout breakage.
- No React/Svelte; dev deps only `vite`, `typescript`, `vitest`.
- Pure modules must not reference `window`/`document`; RGBA via `Uint8ClampedArray`.
- Cannot ask questions: every architectural choice is listed under **Decisions**.

## Key types & data flow
```
Layer   { id; name; visible; opacity: number /*0..100*/; pixels: Uint8ClampedArray /*32*32*4*/ }
Frame   { id; layers: Layer[] /*[0]=bottom*/; hold: number /*1..24*/ }
Palette { id; name; colors: string[] /*#rrggbb*/ }
Document{ version: 1; width:32; height:32; frames: Frame[]; palettes: Palette[];
          activePalette: number; fps: number /*1..24*/; loop: boolean }
AppState{ doc; activeFrame; activeLayerId; color; tool; brushSize: 1|2;
          onionOpacity /*0..100*/; playing }
```
Data flow: `Document` (pure) → `store` mutates via `history` snapshots → `tools` applies
raster primitives to active layer → `composite` flattens a frame → `canvasView` paints
to a 512×512 nearest-neighbor canvas; `serialize`/`png`/`sheet` consume the same model
for save/load/export. Onion skin = `composite(prevFrame)` drawn under the live frame,
view-only, never stored.
Key interfaces:
- `compositeFrame(frame, w, h): Uint8ClampedArray` — alpha-blend visible layers bottom→top.
- `runTool(state, tool, from, to): rasters | null` — preview geometry; `applyStroke` commits.
- `encodePng(width, height, rgba): Uint8Array`; `layoutSheet(frames, cell): {width,height,rgba}`.
- `serializeDocument(doc): string`; `deserializeDocument(json): Document` (throws on bad version).
- `History.push(doc)` / `undo(doc)` / `redo()` — unlimited snapshots.

## Decisions (one line each → DECISIONS.md)
1. Vanilla TS + Vite, dev deps only `vite`/`typescript`/`vitest` — matches architecture directive.
2. Vitest `node` environment against pure modules — avoids jsdom/canvas dependency.
3. RGBA buffers as `Uint8ClampedArray` — matches canvas and tests.
4. `layers[0]` is bottom (draw order); panels render reversed so top is listed first.
5. Layer opacity stored as integer `0..100` — mirrors UI, no conversion drift.
6. Only JSON project save/load + PNG sprite-sheet export; no GIF/APNG — spec says other formats not needed.
7. PNG encoder is pure TS (CRC32 + zlib stored/uncompressed deflate blocks) — no canvas dependency.
8. Serialization is versioned JSON with pixel data base64-encoded via a pure-TS codec — compact and runtime-agnostic.
9. Undo/redo is snapshot-based and unlimited — buffers are 4 KB, cheap and simple.
10. Palette presets: Default 16 + PICO-8 + Game Boy (≥2 switchable); per-document palette saved in project JSON.
11. Frame timing: display seconds = `hold / fps`; play cycles frames, loop toggle repeats.
12. Onion skin is a view-only composite of the previous frame with configurable opacity.
13. Shortcuts attach to a focusable canvas container (`tabindex=0`); controls refocus it; inputs never intercepted.
14. 32×32 fixed, ≤64 frames, default document starts with 4 layers.
15. Existing orchestrator README moves to `TOOLING.md`; new `README.md` documents SpriteForge.

## Implementation phases
Each task ≈ one module + its test file. Keep `INTEGRATION.md` current after every task
(module → exported symbols → importer/mount point; list anything not yet reachable).

### Phase A — pure core model
- A1 **Scaffold**: `package.json` (scripts below), `tsconfig.json` (strict), `vite.config.ts`,
  minimal `index.html`, stub `src/main.ts`, append `.gitignore` (`node_modules/`, `dist/`,
  `coverage/`). Owns toolchain.
- A2 **types + base64** (`model/types.ts`, `model/base64.ts`) + tests for base64 round-trip.
- A3 **raster primitives** (`model/raster.ts`): pencil stamp (size 1/2), Bresenham line,
  rect (outline/fill), midpoint ellipse, flood-fill bucket, eyedropper. Tests per primitive.
- A4 **palette** (`model/palette.ts`): presets + add/remove/reorder/active ops. Tests.
- A5 **document ops** (`model/document.ts`): add/delete/rename/reorder/visibility/opacity
  layers; add/duplicate/delete/reorder frames; hold. Tests incl. 64-frame cap, min 1 layer.
- A6 **compositing** (`model/composite.ts`): visibility + opacity blend. Tests with known colors.
- A7 **serialization** (`model/serialize.ts`): versioned round-trip, reject bad version. Tests.
- A8 **PNG + sheet** (`model/png.ts`, `model/sheet.ts`): CRC32, IHDR/IDAT/IEND, stored blocks;
  grid layout. Tests verify CRC and `node:zlib.inflateSync` round-trip of IDAT.

**Phase A check**: `npm run typecheck && npm test` green; PNG bytes inflate back to expected pixels.

### Phase B — state layer
- B1 **store + history** (`state/store.ts`, `state/history.ts`): subscribe/getState, mutation
  helpers, snapshot undo/redo. Tests for 2 undos + redo, unlimited depth.
- B2 **tool controller** (`state/tools.ts`): active tool, brush size, drag start/update/preview,
  commit. Tests for line/rect preview vs commit and brush cycling.
- B3 **playback** (`state/playback.ts`): pure advance/step/stop logic honoring hold/fps/loop.
  Tests for loop wrap, non-loop stop, step forward/back, hold timing.

**Phase B check**: `npm run typecheck && npm test` green; no UI imports in `state/`.

### Phase C — UI (glue exempt from unit tests; must typecheck/build)
- C1 **canvas view** (`ui/canvasView.ts`): 512×512 nearest-neighbor render, onion-skin layer,
  pointer→pixel mapping, pixel grid.
- C2 **tools panel**: tool buttons + brush size + preview affordance; clicking refocuses canvas.
- C3 **palette panel/editor**: swatches, presets, add/remove/reorder, native color picker.
- C4 **layers panel**: list (top-first), add/delete/rename/reorder, visibility, opacity slider.
- C5 **frames panel**: filmstrip thumbnails, active highlight, add/duplicate/delete/reorder, scrub.
- C6 **playback bar + onion control**: fps, hold, loop, play/pause/stop/step, onion opacity slider.
- C7 **shortcuts** (`ui/shortcuts.ts`): keymap B/E/L/R/O/G/I, `[`/`]`, Ctrl+Z/Ctrl+Shift+Z,
  listener on the focused canvas container only.
- C8 **main.ts wiring**: mount every panel, store subscriptions, render loop.

**Phase C check**: `npm run build` succeeds; dev server shows draw→composite→panel updates
end to end; no console errors.

### Phase D — integration & docs
- D1 **file controls**: download/load project JSON (`ui/fileControls.ts`), wire to serialize.
- D2 **export UI**: PNG sprite-sheet download wired to `encodePng`/`layoutSheet`.
- D3 **docs**: README (build/run/test + features), USERGUIDE (every feature + every shortcut),
  COMPLETION (`section: status (met/partial) — notes` per spec section).
- D4 **validation**: full suite + manual pass at 1280×800 covering every spec section.

**Phase D check**: fresh `npm install && npm run build`; `npm test`; `npm run typecheck`;
manual feature sweep; COMPLETION.md written.
